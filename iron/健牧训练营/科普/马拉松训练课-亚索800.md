## 一、亚索800的含义

亚索800是一个叫做亚索的马拉松运动员无意中发现马拉松成绩和10组800m间歇（跑休比1:1）成绩存在高度关联。

具体是指拿10组800米平均用时基本等同于全马成绩。

举例，假如你可以3分钟跑10组800m，理论上讲全马已经具备破三的能力。当然这里金限于理论上，还要看长距离拉的够不够，跑量积累，阈值强度啥的，赛前准备等等。

## 二、计算800米用时和配速的关系

我们来算一下800m跑3分，大概配速是多少？

3 * 60 / 0.8 / 60 = 3.75分钟/公里， 3.75分/公里 = 3分/公里 + 0.75 * 60 = 45秒/公里 = 3'45''/公里

所以跑一个800m，用时3分，那么配速需要达到3'45''，感觉还是蛮快的。

假如耗时3分30秒呢？ 大概4'22''/公里， 耗时差30秒，配速竟然差37秒/公里。

计算配速的时候需要将时间都转化成秒，然后算出来没公里的用时，这里的单位是分钟，然后再把小时的分钟换化成秒，最后就得到了我们常说的配速了。

比如我我们要破三的话，长度为42.1975KM， 时间是3'00'00， 3 * 60 * 60 / 42.1975 / 60 = 4.2656分钟/公里，然后将0.2656转化成秒等于15.9，就得到最后的配速，大概4分15.9秒。



但是我现在最快的一公里都只能跑到4分钟，那么转化成亚索800，配速是多少？

0.8km * 4'00'' m/km = 3.2m -> 3'18''

所以计算下来，4分配跑800耗时3分18秒，距离3分的耗时还差18秒。
