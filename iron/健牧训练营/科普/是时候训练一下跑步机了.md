最近的天气冷了，但是好的方式还是路跑，跑步机只是次要选项。

跑步机时速对应什么配速呢？

时速：1小时能跑几公里，公里数除以小时

配速：1公里需要几分钟，分钟除以距离

| 跑步机时速km/h | 配速min/km |
| -------------- | ---------- |
| 10             | 6'00       |
| 10.5           | 5'43       |
| 11             | 5'27       |
| 11.5           | 5'13       |
| 12             | 5'00       |
| 13             | 4'37       |
| 14             | 4'17       |

再快我现在就跑不了了，详细的可以查看：[不同配速距离用时表](https://www.xiaohongshu.com/explore/68a481fb000000001d010e11?xsec_token=ABXOeSqDZofObh6gmN8m3xjQoeMfQgAq1nb271hkWg8_8=&xsec_source=pc_search&source=unknown)

按照我今天的课表 14k的4'22-5'15，那么跑步机的时速应该是13.8-11.4，目标是4'40-4'50，12.5对应4'48



看到一个学习过程，就是实践-抽象-还原-新实践，这样一个循环，正好想到了马拉松训练的循环周期，有氧打基础，然后跑出一个新的pb，然后用新pb的有氧配速重新打基础，在跑出新pb的过程。

遇到问题，看见现象，然后通过抽象能力， 提炼背后的底层逻辑，形成模型和理论。接着，通过“还原”能力，找出新的方法轮，投入到新的实践中，解决新的问题，然后，又是新的一轮，如此循环。
