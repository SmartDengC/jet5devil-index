## 指标的含义？

市盈率PE

- 定义： 表示“你愿意为每一块钱的公司盈利致富多少价格”
- 计算：PE = 当前每股股价/每股收益

市净率PB

市销率PS

股息率DID

## 指数估值怎么看？

为什么要了解这方面的内容， 因为从“研究员雷牛牛”每天发的板块估值，在加上《投资中最简单的事情》中提到，买的便宜才是硬道理，估值低的话，同比的话就相当于便宜。

估值是用来表现指数性价比的指数，最常用的估值指标有“PE市盈率“和”PB市净率“，PE适合盈利相对稳定、周期性较弱的板块，如医药，食品饮料等；PB适合于流动性资产比较高的周期性行业，如银行、钢铁、煤炭、猪肉等。

1、如何判断那些指数适用于PE或PB？

我们会判断某个行业是否属于周期性行业，这类指数头件看PB指标。注意：周期性行业的判断有一定的主观性

2、估值高低怎么看？

::: tip 判断百分位高低

- 过高：百分位 > 90%

- 偏高：70% < 百分位 <= 90%

- 适中：30% < 百分位 <= 70%

- 偏低：10% < 百分位 <=  30%

- 过低：百分位 <= 10%

:::

PE百分位代表当前PE在选定区间所处的水平，例如PE百分位为10%，表示只有10%的时候比当前市盈率低，PB百分位同理。

3、数据说明

PE指市盈率（TTM）数值越低，一般认为估值越低，TTM是指截止最近的连续12个月的数据。

==PE(TTM) =∑成分股总市值/∑成分股归母净利润==

PB指市净率（LF）数值越低，一般认为估值越低，LF是指最近一期财报数据。

==PB(LF) = ∑成分股总市值/∑成分股净资产==

估值水平标签的计算口径：指数的PE分为基于近5年的PE数据计算，若不满5年则采用全部历史数据，PB同理。不计算成立时间不足1年的指数估值水平。
