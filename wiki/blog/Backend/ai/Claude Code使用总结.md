如果地区不支持，挂梯子，并设置

```
HTTP_PROXY=http://127.0.0.1:7890 HTTPS_PROXY=http://127.0.0.1:7890 claude
```

7890是你的梯子的代理端口。



```
git config --global --get http.proxy
git config --global --get https.proxy
```

查看git的代理信息。
