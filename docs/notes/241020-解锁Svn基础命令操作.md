版本控制操作软件界面众多，但我独爱命令行操作！

<!-- more -->

svn是一个版本控制的软件，支持主流的操作系统，之前在win上面使用，多是使用svn的界面来操作的，但是换到mac os，没有刻意去装svn的客户端，多是使用命令来实现。

## 一、安装

对于下载，有homebrew的直接运行下方命令即可安装：

```
brew install subversion
```

win的话就去官网下载相应的安装包安装就可以；安装成功了，我们就开始学习svn的操作命令。

## 二、操作命令



### 2.1 svn co

svn co是命令svn checkout的缩写版本，两个命令的结果是相同的，都是从代码仓库拉取文件到本地。

```shell
svn co svn//localhost:3819/svn/xxx1/svntest
svn co svn//localhost:3819/svn/xxx1/svntest save-dir // 指定拉取文件存放路径
svn co svn//localhost:3819/svn/xxx1/svntest --username username --password password  // 使用指定用户拉取文件
```

### 2.2 svn info

查看版本库信息

```shell
svn info  // 查看当前目录版本信息
svn info save-dir  // 查看指定路径版本信息
svn info svn//localhost:3819/svn/xxx1/svntest // 查询远程url版本信息
```

### 2.3 svn add 

添加文件或目录到暂存区

```shell
svn add a.txt
svn add *.log
svn add test/
```

### 2.4 svn commit

提交到版本库

```shell
svn commit -m "feat: 提交本地代码"   // 提交所有add的文件
svn commit -m "feat: 提交本地代码" a.txt  // 提交a.txt问津
```

### 2.5 svn st

查看文件或目录状态

```shell
svn st
M       app/src/main/java/ys/manufacture/sparepart/job/handle/CutBatchDetermineHandler.java  // 前面的M表示修改
A       app/src/main/java/ys/manufacture/sparepart/job/intercept/FilterScheduledAop.java  // A 表示添加
D       app/src/main/java/ys/manufacture/sparepart/job/intercept/FilterPackOrder.java  // D 表示删除
?       app/webDownLoad
?       app/xz_sparepart_app
svn st -q
svn st -u
svn st -v
```

- -p 不显示未添加的文件
- -u 显示版本信息
- -v显示全部信息：第二列显示工作版本号，第三列和第四列显示最后一次修改的版本号和修改人

### 2.6 svn rm

同svn delete，删除文件。

```shell
svn rm a.txt
```

### 2.7 svn up

同svn update，使用远程文件，更新本地文件。

```shell
svn up
svn up -r xxx  // 更新到指定版本的代码，在新版本代码出现问题时，可以用这个命令回到之前的版本
svn up /path/to/file-or-dir  // 仅更新指定文件或目录
```

### 2.8 svn log

查看提交日志。

```shell
svn log
svn log a.txt
svn log -l 3 // 查询最新的三次提交
```
