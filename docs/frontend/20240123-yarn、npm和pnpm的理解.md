修改本地 yarn 的版本

我们使用 yarn 来管理

```
yarn set version <版本号>
yarn set version 2.4.3
```

```
npm install -g yarn
npm uninstall -g yarn
npm view yarn versions  // 查看yarn提供的版本
```
