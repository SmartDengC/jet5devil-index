### 快速入门 Vue.js 的前端项目：待办事项列表

#### 项目概述
本项目是一个简单的待办事项列表应用，使用Vue.js实现基本的功能，包括添加任务、删除任务、标记完成以及搜索功能。通过该项目，你可以快速掌握Vue.js的核心技术，如数据绑定、组件化开发和状态管理。

#### 技术栈
- **Vue.js**: 响应式JavaScript框架
- **Vuex**: Vue.js的状态管理库
- **Vue Router**: 用于实现页面导航（可选）
- **Vite**: 现代的构建工具，替代Webpack

#### 项目结构
```
todo-app/
├── src/
│   ├── App.vue          # 主组件
│   ├── store/           # Vuex 存储模块
│       └── index.js     # Store 实例
│   ├── components/      # 组件目录
│       ├── TodoList.vue  # 待办事项列表组件
│       ├── AddTodo.vue    # 添加任务表单组件
│       └── SearchTodo.vue # 搜索功能组件
├── package.json         # 项目依赖管理文件
└── README.md            # 项目说明文档
```

#### 详细步骤

1. **初始化项目**
   - 安装Node.js和npm（若未安装）。
   - 安装Vue CLI：
     ```bash
     npm install -g vue-cli
     ```
   - 使用Vue CLI创建新项目：
     ```bash
     vue create todo-app
     ```
   - 进入项目目录并安装依赖：
     ```bash
     cd todo-app
     npm install
     ```

2. **配置Vuex**
   - 在`src`目录下创建`store`文件夹，并添加`index.js`。
   - 配置Store，用于管理待办事项的状态。

3. **创建主组件App.vue**
   - 导入Vue和Vue Router（可选）。
   - 定义主要的视图结构，包含各个功能组件。

4. **开发TodoList组件**
   - 展示所有任务列表。
   - 实现删除和完成任务的功能，通过事件处理器更新Store的状态。

5. **实现AddTodo表单**
   - 创建表单输入框，收集用户输入的任务名称和优先级。
   - 提交后将新任务添加到Store中。

6. **添加Search组件**
   - 添加搜索输入框，根据用户输入过滤任务列表。
   - 使用Vue的计算属性或watch监听搜索关键词的变化，并更新显示的任务列表。

7. **集成Vuex状态管理**
   - 在App.vue中注入store实例：
     ```vue
     import { createStore } from 'vuex';
     
     const store = createStore({
       state: () => ({
         todos: []
       }),
       mutations: {
         addTodo(state, todo) {
           state.todos.push(todo);
         },
         deleteTodo(state, id) {
           state.todos.splice(id, 1);
         },
         toggleComplete(state, id) {
           state.todos[id].completed = !state.todos[id].completed;
         }
       }
     });
     
     export default {
       components: { TodoList, AddTodo, SearchTodo },
       store
     };
     ```

8. **开发组件通信**
   - 在主组件App.vue中，将store传递到子组件：
     ```vue
     <template>
       <AddTodo v-model:todo="newTodo" @submit="addTodoHandler"/>
       <SearchTodo @search="handleSearch"/>
       <TodoList :todos="filteredTodos" @delete="deleteTodo" @complete="toggleComplete"/>
     </template>
     ```

9. **实现任务操作**
   - 在子组件中，通过事件处理器和store的mutations方法来更新状态。

10. **添加过滤功能（可选）**
    - 添加下拉菜单，选择显示所有、未完成或已完成的任务。
    - 根据当前过滤类型，动态调整显示的任务列表。

11. **测试应用功能**
    - 确保所有功能正常工作：任务的增删改查，搜索和过滤功能。
    - 检查状态更新是否及时反映到视图中。

#### 最终代码示例

- **App.vue**
  ```vue
  <template>
    <div id="app">
      <h1>待办事项列表</h1>
      <AddTodo @submit="addTodo"/>
      <SearchTodo @search="handleSearch"/>
      <TodoList :todos="filteredTodos" @delete="removeTodo" @complete="toggleComplete"/>
    </div>
  </template>
  
  <script>
    import AddTodo from './components/AddTodo.vue';
    import TodoList from './components/TodoList.vue';
    import SearchTodo from './components/SearchTodo.vue';
  
    export default {
      components: { AddTodo, TodoList, SearchTodo },
      data() {
        return {
          newTodo: '',
          searchQuery: ''
        }
      },
      computed: {
        filteredTodos() {
          const searchTerm = this.searchQuery.toLowerCase();
          return this.todos.filter(todo =>
            todo.title.toLowerCase().includes(searchTerm)
          );
        }
      },
      methods: {
        addTodo(newTodo) {
          this.$store.commit('addTodo', newTodo);
        },
        removeTodo(id) {
          this.$store.commit('deleteTodo', id);
        },
        toggleComplete(id) {
          this.$store.commit('toggleComplete', id);
        },
        handleSearch(query) {
          this.searchQuery = query;
        }
      }
    };
  </script>
  ```

- **AddTodo.vue**
  ```vue
  <template>
    <form @submit.prevent="handleSubmit">
      <input v-model="todo.title" placeholder="输入任务名称"/>
      <select v-model="todo.priority">
        <option value="low">低</option>
        <option value="medium">中等</option>
        <option value="high">高</option>
      </select>
      <button type="submit">添加任务</button>
    </form>
  </template>
  
  <script>
    export default {
      data() {
        return {
          todo: {
            title: '',
            priority: 'low',
            completed: false
          }
        }
      },
      props: {
        todos: {
          type: Array,
          required: true
        }
      },
      methods: {
        handleSubmit() {
          this.$emit('submit', this.todo);
          this.todo.title = '';
          this.todo.priority = 'low';
        }
      }
    };
  </script>
  ```

- **TodoList.vue**
  ```vue
  <template>
    <ul>
      <li v-for="(todo, index) in todos" :key="index">
        <input type="checkbox" v-model="todo.completed"/>
        <span :class="{ completed: todo.completed }">{{ todo.title }}</span>
        <button @click="$emit('delete', index)">删除</button>
      </li>
    </ul>
  </template>
  
  <script>
    export default {
      props: {
        todos: {
          type: Array,
          required: true
        }
      },
      methods: {
        removeTodo(index) {
          this.$emit('delete', index);
        }
      }
    };
  </script>
  ```

- **SearchTodo.vue**
  ```vue
  <template>
    <input v-model="searchQuery" type="text" placeholder="搜索任务"/>
  </template>
  
  <script>
    export default {
      data() {
        return {
          searchQuery: ''
        }
      },
      methods: {
        handleSearch() {
          this.$emit('search', this.searchQuery);
        }
      }
    };
  </script>
  ```

#### 结论

通过以上步骤，我们成功地构建了一个功能完善的待办事项列表应用。该应用包含了添加、删除、完成任务以及搜索和过滤功能。组件之间的通信通过Vue的事件系统实现，而状态管理则使用了Vuex或简单的store结构。这种结构使得代码清晰，组件复用性高，并且易于维护。

### 步骤详解：构建一个待办事项列表应用

#### 1. 确定需求
- **目标**：创建一个允许用户添加、删除、标记为完成，并能搜索和过滤任务的待办事项列表。
- **功能模块**：
  - 添加任务（带有优先级选择）
  - 删除任务
  - 标记任务为完成或未完成
  - 搜索任务
  - 过滤任务（如显示所有、未完成、已完成的任务）

#### 2. 技术选型
- **框架**：使用Vue.js作为前端框架。
- **状态管理**：选择简单的数据存储方式，如Vuex或直接在组件中使用`store`对象。
- **组件化开发**：将应用拆分为多个可复用的组件（AddTodo、TodoList、SearchTodo等）。

#### 3. 设计组件结构
- **App.vue**：主组件，负责协调各个子组件，管理全局状态。
- **AddTodo.vue**：添加任务的表单组件，包含输入字段和提交按钮。
- **TodoList.vue**：显示所有任务的列表，每个任务可以被勾选完成或删除。
- **SearchTodo.vue**：提供搜索功能的输入框。

#### 4. 实现全局状态管理
- 使用一个简单的`store`对象来维护应用的状态，或者集成Vuex进行更复杂的状态管理。这里我们使用一个基本的`store`结构：

```javascript
import Vue from 'vue';

const store = {
  state: () => ({
    todos: []
  }),
  mutations: {
    addTodo(state, todo) {
      state.todos.push(todo);
    },
    deleteTodo(state, id) {
      state.todos.splice(id, 1);
    },
    toggleComplete(state, id) {
      state.todos[id].completed = !state.todos[id].completed;
    }
  }
};

Vue.prototype.$store = store;
```

#### 5. 开发AddTodo组件
- **功能**：允许用户输入任务名称和优先级，点击提交后将新任务添加到`store`中。
- **实现步骤**：
  - 创建表单，包含输入框、下拉选择（优先级）和提交按钮。
  - 使用Vue的双向绑定（v-model）来跟踪输入值。
  - 提交事件触发时，调用父组件提供的`submit`事件，将新任务传递给`store`。

```vue
<!-- AddTodo.vue -->
<template>
  <form @submit.prevent="handleSubmit">
    <input v-model="todo.title" placeholder="输入任务名称"/>
    <select v-model="todo.priority">
      <option value="low">低</option>
      <option value="medium">中等</option>
      <option value="high">高</option>
    </select>
    <button type="submit">添加任务</button>
  </form>
</template>

<script>
export default {
  data() {
    return {
      todo: {
        title: '',
        priority: 'low',
        completed: false
      }
    }
  },
  methods: {
    handleSubmit() {
      this.$emit('submit', this.todo);
      this.todo.title = '';
      this.todo.priority = 'low';
    }
  }
};
</script>
```

#### 6. 开发TodoList组件
- **功能**：显示所有任务，并允许用户删除或标记为完成。
- **实现步骤**：
  - 遍历`store`中的`todos`数组，生成每个任务的列表项。
  - 使用Vue的事件发射（$emit）来通知父组件执行相应操作（删除、标记完成）。

```vue
<!-- TodoList.vue -->
<template>
  <ul>
    <li v-for="(todo, index) in todos" :key="index">
      <input type="checkbox" v-model="todo.completed"/>
      <span :class="{ completed: todo.completed }">{{ todo.title }}</span>
      <button @click="deleteTodo(index)">删除</button>
    </li>
  </ul>
</template>

<script>
export default {
  props: ['todos'],
  methods: {
    deleteTodo(index) {
      this.$emit('delete', index);
    }
  }
};
</script>
```

#### 7. 开发SearchTodo组件
- **功能**：提供搜索输入框，允许用户按任务名称搜索。
- **实现步骤**：
  - 创建一个输入框，使用v-model跟踪输入值。
  - 将输入值传递给父组件，用于过滤显示的任务。

```vue
<!-- SearchTodo.vue -->
<template>
  <input type="text" v-model="searchQuery" placeholder="搜索任务...">
</template>

<script>
export default {
  data() {
    return {
      searchQuery: ''
    }
  },
  methods: {
    handleSearch() {
      this.$emit('search', this.searchQuery);
    }
  }
};
</script>
```

#### 8. 组合所有组件在App.vue中
- **功能**：将各个组件整合到一起，并协调它们的交互。
- **实现步骤**：
  - 在`App.vue`中引入并使用所有子组件。
  - 使用`store`中的数据来过滤和显示任务列表。

```vue
<!-- App.vue -->
<template>
  <div id="app">
    <h1>待办事项</h1>
    <AddTodo @submit="addTodo"/>
    <SearchTodo @search="filterTodos"/>
    <TodoList :todos="filteredTodos"/>
  </div>
</template>

<script>
import AddTodo from './components/AddTodo.vue';
import TodoList from './components/TodoList.vue';
import SearchTodo from './components/SearchTodo.vue';

export default {
  components: {
    AddTodo,
    TodoList,
    SearchTodo
  },
  data() {
    return {
      filteredTodos: this.$store.state.todos
    }
  },
  methods: {
    addTodo(todo) {
      this.$store.commit('addTodo', todo);
    },
    filterTodos(query) {
      this.filteredTodos = this.$store.state.todos.filter(todo =>
        todo.title.toLowerCase().includes(query.toLowerCase())
      );
    }
  }
};
</script>
```

#### 9. 实现搜索和过滤功能
- **实现步骤**：
  - 在`App.vue`中监听`SearchTodo`组件的`search`事件，调用`filterTodos`方法。
  - `filterTodos`方法根据输入的查询字符串过滤`store`中的任务列表。

#### 10. 测试应用
- **测试添加任务**：确保新任务正确添加到列表，并显示在`TodoList`中。
- **测试删除功能**：点击删除按钮，检查任务是否从列表中移除。
- **测试完成标记**：勾选任务的复选框，确认任务状态更新为已完成。
- **测试搜索功能**：输入不同的查询字符串，验证任务列表是否正确过滤。

#### 11. 可能的扩展和优化
- **持久化存储**：将待办事项保存到本地存储（如 localStorage），以便在页面刷新后数据不丢失。
- **优先级显示**：根据任务的优先级使用不同颜色或图标显示。
- **任务分类**：允许用户为任务添加类别，增加过滤选项（按类别筛选）。
- **排序功能**：支持按优先级、完成时间等字段对任务进行排序。
