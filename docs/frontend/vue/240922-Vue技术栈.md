## 学习创建vue项目

可以直接使用yarn init来创建，也可以使用vue-cli来创建。

Yarn 创建：

```vue
(base) ➜ test1 yarn init -y
yarn init v1.22.21
warning The yes flag has been set. This will automatically answer yes to all questions, which may have security implications.
success Saved package.json
✨  Done in 0.02s.
(base) ➜ test1 yarn add webpack webpack-cli --dev
```

webpack的打包命令：`npx webpack`

Vue-cli创建： `vue create project_name`
