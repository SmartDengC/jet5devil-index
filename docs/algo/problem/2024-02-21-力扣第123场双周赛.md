## [3024. 三角形类型](https://leetcode.cn/problems/type-of-triangle/)

先判断是不是三角行，如果是在判断是哪一类三角形。

```python
class Solution:
    def triangleType(self, nums: List[int]) -> str:
        # is triangle
        a,b,c = nums
        if a+b<=c or a+c<=b or b+c<=a:
            return 'none'
        _nums = set(nums)
        if len(_nums) == 1:
            return 'equilateral'
        if len(_nums) == 2:
            return 'isosceles'
        if len(_nums) == 3:
            return 'scalene'
        return 'none'
```

看了灵神的题解，不得不说，他们的题解的思路就是比现在的自己要好，要精髓。

```python
class Solution:
    def triangleType(self, nums: List[int]) -> str:
        nums.sort()
        a, b, c = nums

        if a+b <= c: # 排序后，只需要比较a+b和c
            return 'none'
        if a == c:  # 排序了，如果a==c，说明b==c
            return 'equilateral'
        if a == b or b == c:
            return 'isosceles'
        return 'scalene'
```
