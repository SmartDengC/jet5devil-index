## [3046. 分割数组](https://leetcode.cn/problems/split-the-array/)

给你一个长度为偶数的整数数组nums，你需要将这个数组分割成nums1和nums2两部分，要求：

- nums1.length == nums2.length == nums.length/2
- nums1包含互不相同的元素
- nums2包含互不相同的元素

如果能分割的话就返回true，否则返回false



根据题意，如果nums[i]的出现的次数超过2，则无法分割，否则可以分割

```python
class Solution:
    def isPossibleToSplit(self, nums: List[int]) -> bool:
        # most_common(n) 返回出现频率最高的n个元素
        # return Counter(nums).most_common(1)[0][1] <= 2  
        
        a = Counter(nums)
        for k, v in a.items():
            if v>2:
                return False
        return True
```

Counter(nums).most_common() 参考[Python中的Counter.most_common()方法](https://blog.csdn.net/qq_36134437/article/details/103245281)
