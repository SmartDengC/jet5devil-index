## [209. 长度最小的子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/)

> 给定一个含有n个正整数的数组和一个正整数target。
>
> 找出该数组中满足其总和大于等于target的长度最小的连续子数组，并返回其长度，如果不存在符合条件的子数组，返回0。

滑动窗口，将right加入进去之后，移动left判断是否满足条件，如果满足就把left指向的元素干掉。

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        // 滑动窗口
        int n = nums.length;
        int left = 0;
        int sum = 0;
        int ans = n+1;
        for(int right=0;right<nums.length;right++){
            sum += nums[right];
            while(sum - nums[left] >= target){
                sum -= nums[left];
                left++;
            }
            if(sum>=target){
                ans = Math.min(ans, right-left+1);
            }
        }
        return ans <= n?ans: 0;
    }
}
```



## [1456. 定长子串中元音的最大数目](https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length/)

> 给你一个字符串s和整数k，请返回字符串s中长度为k的单个字符串中可能包含的最大元音字母数。
>
> 英文中的元音字母为a,e,i,o,u.

如果枚举长度为k的子字符串在判断包含几个元音字母的话，会出现超时的情况。

在遍历过程中，我们使用一个公式来动态的计算定长字符串包含的元音字母的个数。

**待画图理解**

```java
class Solution {
    public int maxVowels(String s, int k) {
        int n = s.length();
        int cnt1 = 0;
        for(int i =0;i<k;i++){  // 求出来前k个字符中包含的元音字母的个数
            cnt1 += isVowel(s.charAt(i));
        }
        int ans = cnt1;
        for(int i=k;i<n;i++){  // 每次移动一个下标，判断存在几个元音字母，
            // cnt = cnt2 + idx[i] - idx[i-k]   就是判断最后一个字母和去掉的那个字母
            cnt1 += (isVowel(s.charAt(i))- isVowel(s.charAt(i-k)));
            ans = Math.max(ans, cnt1);
        }
        return ans;
    }
    public int isVowel(char ch){
        return ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u' ? 1:0;
    }
}
```

Java 字符串操作：

1、`String.charAt(idx);`

2、判断是否元音字母 `ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u' ? 1:0;`

3、`String.length();`

4、`List.size();`

5、`int[] a.length;`



##  [2269. 找到一个数字的 K 美丽值](https://leetcode.cn/problems/find-the-k-beauty-of-a-number/)

就是简单模拟，遍历找到对应长度为k的数字，判断是不是num的约数。

```java
class Solution {
    public int divisorSubstrings(int num, int k) {
        String s = String.valueOf(num);  // 转成字符串
        int n = s.length();  
        int cnt = 0;
        for(int i=0;i<n-k+1;i++){  // 遍历到[0,n-k+1)
            int b = Integer.parseInt(s.substring(i, i+k));  // 转成数字  
            if(b!=0 && num % b == 0){ // 判断
                cnt++;
            }
        }
        return cnt;
    }
}
```

## [643. 子数组最大平均数 I](https://leetcode.cn/problems/maximum-average-subarray-i/)

> 给你一个由n个元素组成的整数数组nums和一个整数k
>
> 请你找出平均数最大且长度为k的连续子数组，并输出改最大的平均数。

思路与1456解法相同。

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        int n = nums.length;
        int preSum = 0;
        for(int i =0;i<k;i++){
            preSum += nums[i];
        }
        int ans = preSum;
        for(int i=k;i<n;i++){
            preSum += (nums[i] - nums[i-k]);
            ans = Math.max(ans, preSum);
        }
        return (double)ans/k;
    }
}
```

java语法：

1、`Double b = 0.0;`

2、`1.0 * ans/k;` 1.0 * x将最后的结果转成double类型

3、`(double)ans/k;` 将最后的结果转成double类型
