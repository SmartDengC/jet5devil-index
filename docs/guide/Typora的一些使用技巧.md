## 一、配置Typora主题

下载下来typra的主题，然后在设置里面打开主题的配置文件，然后将下下来的主题文件拷贝到配置目录即可，在设置的时候就可以选择相应的主题。



## 二、Typora快捷键

- command + b 粗体



## 三、Typora知识点

- 专注模式： 高亮光标所在行，其余行呈灰色。

- 打字机模式：就是光标始终在屏幕中间。
