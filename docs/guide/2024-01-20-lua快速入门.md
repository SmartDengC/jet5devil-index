## 本地安装lua运行环境
我们学习使用lua需要有lua的运行环境，我看b站视频里面，说是可以在luatos网页里执行代码，我这里暂时没有打开，就尝试在本地安装一个，也不是很难。


我们可以从官网中可以找到lua安装的方式:
```shell
curl -L -R -O https://www.lua.org/ftp/lua-5.4.6.tar.gz
tar zxf lua-5.4.6.tar.gz
cd lua-5.4.6
make all test
make all install
```
如果`make all test`出现权限不匹配的话， 可以使用sudo来执行.
执行完之后，我们lua -a 检查一下是否安装成功

```shell
(base) ➜ lua-5.4.6 lua -v
Lua 5.4.6  Copyright (C) 1994-2023 Lua.org, PUC-Rio
```
