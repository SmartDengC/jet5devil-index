## 一、Deepseek简单概述

春节期间，我还沉醉在春节的喜悦当中，但是推理大模型deepseek开启了觉醒。

简单使用还是很方便的，一个是直接访问上面的官网，还有一种就是下载app。

deepseek现在有两种模型，一种是deepseek v3，一种是deepseek r1，就是常说的深度思考。

模型的训练时间是2024年7月，就是说7月之后的信息他是不能了解的，除非你开启联网搜索。

Deepseek在疯狂的训练数据，现在的基准数据到了2024年10月14号了。

deepseek官方开放了api。

## 四、本地部署

[cherry studio](https://cherry-ai.com/)，一个ai平台。

### 4.1 ollama

[ollama](https://ollama.com/) 是一个专为本地环境中运行和定制大型语言模型而设计的工具，因为deepseek是开源的，简单来说就是将模型下载下来，然后在ollama上面跑。

```
ollama -v
ollama pull deepseek-r1:7b
```

下载太慢了。

![image-20250207135333787](https://gitee.com/jet5devil/typora-picture/raw/master/mac_img/202502071353843.png)
